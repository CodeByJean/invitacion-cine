# 🎬 Una Noche de Cine 💗

Una experiencia web interactiva diseñada como una invitación especial para una cita de cine, con mini juegos, selección de comida, mapa interactivo y un ticket final personalizado.

🌐 **Demo en vivo:** [https://codebyjean.github.io/invitacion-cine/](https://codebyjean.github.io/invitacion-cine/)

---

## ✨ Características

- 🌟 **Atrapa las estrellas:** Mini juego interactivo para comenzar la experiencia.
- 💌 **Pregunta interactiva:** Botón travieso que huye al intentar presionar "No".
- 🗺️ **Ruta de la cita:** Mapa interactivo con paradas y elecciones para el trayecto.
- 🍿 **Elección del menú:** Opciones animadas para elegir la comida favorita.
- 🎟️ **Boleto de cine digital:** Ticket final personalizado y opción para compartir o confirmar por WhatsApp.
- 📱 **Totalmente responsivo:** Optimizado tanto para dispositivos móviles como de escritorio.
- 🎨 **Estilo visual:** Gradientes nocturnos, tipografías elegantes y animaciones fluidas con CSS y JavaScript puro (Vanilla JS).

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3** (Animaciones, variables CSS, gradientes y diseño responsivo)
- **JavaScript (Vanilla)**
- **Google Fonts** (*Shippori Mincho* & *Zen Maru Gothic*)
